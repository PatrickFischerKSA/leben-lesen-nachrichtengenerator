# Leben lesen – Nachrichtengenerator

Statische Webanwendung für die FM2 der Kantonsschule Ausserschwyz. Sie erstellt eine Teams-Nachricht für das Kreativprojekt «Leben lesen» mit Live-Vorschau, Eingabeprüfung und Kopierfunktion.

## Lokal öffnen

Öffne `index.html` im Browser. Die Anwendung benötigt weder Installation noch Build. Die Vorschau lässt sich bei Bedarf auch manuell kopieren.

## Auf GitHub Pages veröffentlichen

1. Erstelle ein GitHub-Repository und lade den **Inhalt** dieses Ordners ins Stammverzeichnis des Branches `main`. Übernimm auch die Datei `.nojekyll`.
2. Wähle unter **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch**.
3. Wähle `main` und `/(root)` und speichere. GitHub zeigt die veröffentlichte Adresse danach unter **Settings → Pages** an.

Die relativen Asset-Pfade funktionieren unter einer Repository-URL wie `https://<konto>.github.io/<repository>/`.

## Verwendung

Thema, Mitglieder, Koordinationsperson, Mobilnummer, Zeitfenster und Treffpunkt erfassen. Bei Bedarf Kommunikationsmöglichkeiten und eine persönliche Mitteilung ergänzen. **Teams-Nachricht kopieren** wählen und den Text in den Gruppenchat einfügen.

Alle Eingaben werden im Browser verarbeitet. Die Anwendung verwendet keine Speicherung, Analyse, externen Bibliotheken oder APIs und versendet keine Nachrichten.
